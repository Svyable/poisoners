THE MEASUREMENT SYSTEM / 005

One planet.
Many kinds of damage.

Emissions are only the opening observation. The research architecture now defines independently measurable dimensions spanning toxic releases, exposure, clinical outcomes, ecosystems, agriculture, pharmaceuticals, justice and remediation. These are metric specifications — not fabricated harm scores.

READ THE OPERATING PROTOCOL ↗
!

Measured does not mean proven harmful. The current company-level ledger contains production-linked greenhouse gas emissions only. No chemical-specific facility exposure, human injury, company-attributable deaths or litigation outcome has been calculated from those values. No single composite Poison Score is published.
