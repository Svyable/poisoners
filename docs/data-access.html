03 / REPRODUCIBILITY

Audit the public build.

Source registries and generated assets are versioned in the repository. The project uses Node.js 22+ and the built-in test runner; no package installation is required for these checks.

node scripts/build-foundation.cjs --check
node scripts/verify.cjs
node --test scripts/foundation.test.cjs
node scripts/check-site-links.cjs

Changes should preserve input provenance, original units, clear time boundaries and reproducible transformations. Records under review are not automatically promoted into public causal claims.

WHAT THIS DATA IS NOT

No normalized corporate toxicity score, no confirmed deaths per company, no finding of illegal conduct, and no fully completed dossiers for all 100 target slots.

Company home country is for navigation, not a map of emission sites. Corporate and national totals cannot be summed.

04 / RESPONSIBLE REUSE

Public evidence. Private people.

Never place claimant identities, addresses, patient records or privileged material in the public repository. Investigative allegations and legal actions must go through independent review and appropriate counsel.
